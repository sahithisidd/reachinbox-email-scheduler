# ReachInbox Email Job Scheduler

🚀 **Live Demo:** https://reachinbox-scheduler-frontend-8lmi.onrender.com

🔗 **Backend:** https://reachinbox-email-scheduler-erzy.onrender.com

An email job scheduling system built with TypeScript, Express.js, React, BullMQ, Redis, PostgreSQL, Elasticsearch, and Ethereal Email.

## ✨ Features

- Google OAuth authentication
- Bulk email scheduling using CSV/TXT files
- Persistent delayed jobs using BullMQ and Redis
- Configurable delay between emails
- Hourly email rate limiting
- PostgreSQL database persistence
- Elasticsearch email indexing and search
- Slack rate-limit notifications
- BullMQ live queue dashboard
- Email status tracking
- React + TypeScript frontend
